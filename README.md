# NZ Election 2026 Guide

A free, neutral, phone-friendly guide to the 2026 New Zealand general election: key voting dates, polls, party policies in each party's own words, and debates.

Live site: https://xiangyu-song.github.io/nz-election-2026/

- Every poll figure and policy quote links to its source.
- Policies are quoted word for word from each party's own website.
- This guide is independent and not affiliated with any political party or the Electoral Commission. Official information: https://vote.nz/

Data lives in the `data/` folder; the page in `index.html` reads it.
